# Fairy Tale Kingdom

A watchable pixel kingdom for Knowledge Quest — React + Phaser 3.

See the long-term plan in [docs/ROADMAP.md](docs/ROADMAP.md).

## Run locally

From the monorepo root:

```bash
npm install
npm run start:fairy-tale-kingdom
```

Open http://localhost:4400/

Or with the host (configure curriculum, then launch from **Choose a game**):

```bash
npm run start:host
npm run start:fairy-tale-kingdom
```

## Build

```bash
npm run build:fairy-tale-kingdom
```

Production Pages path: `/lemon-brains/games/fairy-tale-kingdom/`
